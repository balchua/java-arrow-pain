## Arrow IPC → DuckDB Load Benchmark — All Types (`ArrowFileLoadBenchmarkTest`)

For each type the test: generates the XML if absent → parses XML to Arrow → exports
the three Arrow IPC files → simulates a downstream consumer loading those files
directly into DuckDB (no XML re-parsing).

> the load more efficiently.
